1. Live data

The backend requests BTCUSDT OHLCV candlesticks from Bybit API at runtime. The system does not depend on a local CSV file.

2. Features

The model uses returns, volatility, volume signals, moving averages, RSI, MACD and Ichimoku-based indicators.

3. Forecast

The output is a binary direction: expected growth or fall, confidence, metrics, baseline comparison and interpretable PDT rules.
